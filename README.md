# OKINAMAP v2.2

バージョン1を基に、次の5点だけを追加・変更しています。

1. 中央の案内表示を削除
2. 同一地点のスポット数を数字バッジで表示
3. 左上ロゴを丸型ボタンに変更
4. 左上ロゴから現在地を取得し、赤い通常ピンを表示
9. 短いロゴ起動アニメーションを追加

## v2.2の位置ずれ対策

MapLibreが緯度経度に固定する要素を、幅0・高さ0の `marker-anchor` にしました。
カテゴリピンと数字バッジは、この座標基準点から絶対配置しています。
そのため、数字バッジの有無やズーム倍率が座標基準へ影響しません。

## 反映前の注意

- `config.js` にMapTiler APIキーを入力してください。
- 正式ロゴは `assets/logo.svg` と `assets/logo-symbol.svg` に上書きしてください。
- リポジトリ直下へ、このフォルダーの中身をアップロードしてください。
