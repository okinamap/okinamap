# OKINAMAP v2

## 更新内容
- 中央の案内表示を削除
- 同一地点のスポット件数を数字バッジで表示
- 左上ロゴを丸型の現在地ボタンに変更
- 現在地を赤いハート型ピンで表示
- カテゴリピンを差し替え可能な外部SVGへ変更
- 短いロゴ起動アニメーションを追加
- 説明スライドは未実装

## 導入
1. `config.js` のAPIキーを入力します。
2. 正式なフルロゴを `assets/logo.svg`、丸ボタン用シンボルを `assets/logo-symbol.svg` に置き換えます。
3. カテゴリピンは `assets/markers/` 内の同名SVGを置き換えるだけで差し替えられます。
4. リポジトリ直下へ全ファイルをアップロードします。

## 現在地
左上ロゴボタンを押した時だけ位置情報を求めます。現在地が設定範囲外なら、地図を移動せず通知します。GitHub PagesのHTTPS上で確認してください。
