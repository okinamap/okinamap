# OKINAMAP v2 selected update

バージョン1を基に、指定された5項目だけを変更した版です。

## 実装した変更
1. 「地図のピンをタップ」を削除
2. 同一地点のスポット数を数字バッジで表示
3. 左上ロゴを丸型ボタンに変更
4. 左上ロゴボタンから現在地を取得し、赤い通常ピンを表示
9. 短いロゴ起動アニメーションを追加

カテゴリピンのデザインなど、上記以外はバージョン1の仕様です。

## 設定
- `config.js` にMapTiler APIキーを入力してください。
- 正式なフルロゴは `assets/logo.svg` に上書きしてください。
- 左上ボタン用シンボルは `assets/logo-symbol.svg` に上書きしてください。

## GitHubへの反映
リポジトリ直下のファイルをこのフォルダーの中身で置き換えてください。`config.js` のAPIキーを上書きで失わないよう注意してください。
